# Majesty Cares NGO Website

This is a static website for Majesty Humanitarian Care & Social Welfare Initiative.

## What is included

- Home page
- About page
- Operation Save Our Kids campaign page
- Past Projects page
- Gallery page
- Donate page
- Contact page
- Responsive CSS
- Simple JavaScript for mobile navigation, gallery filtering, and donation account copy button
- Optimized images from the provided NGO asset pack

## How to publish on GitHub Pages

1. Create a new GitHub repository.
2. Upload all files and folders inside this website folder to the repository root.
3. Go to Settings.
4. Open Pages.
5. Under Build and deployment, choose Deploy from a branch.
6. Select the main branch and root folder.
7. Save.
8. GitHub will give you a free public website URL after deployment.

## Editing notes

- Edit text directly inside the HTML files.
- Replace images inside assets/images if needed.
- Edit colors and layout inside assets/css/styles.css.
- No backend, no payment gateway, and no contact form are required for this free static version.

## Important content note

This website uses real Majesty Cares project photos as field evidence. It does not use identifiable photos of kidnapped children as promotional material. The crisis context is presented through reputable news links and respectful language.
